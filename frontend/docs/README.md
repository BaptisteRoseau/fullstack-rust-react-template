# `docs/`

Long-form architecture and practice guides (from the bulletproof-react methodology this frontend
follows). Background reading for humans; the actionable, repo-specific version lives in the
`.claude/skills/frontend-react-*` skills and the per-folder `README.md` files.

| Doc                                                                | Topic                                                       |
| ------------------------------------------------------------------ | ----------------------------------------------------------- |
| `application-overview.md`                                          | The domain (users, teams, discussions, comments) and roles. |
| `project-structure.md`                                             | Feature-based layout + the unidirectional import rules.     |
| `components-and-styling.md`                                        | Component best practices, libraries, styling.               |
| `api-layer.md`                                                     | The schema + fetcher + hook endpoint pattern.               |
| `state-management.md`                                              | Server vs. client vs. form state.                           |
| `testing.md`                                                       | Testing pyramid and tooling.                                |
| `error-handling.md`, `security.md`, `performance.md`               | Cross-cutting concerns.                                     |
| `project-standards.md`, `deployment.md`, `additional-resources.md` | Standards, deploy, links.                                   |

For a single repo-specific summary of the actual stack and tree, see `../../frontend-structure.md`.
