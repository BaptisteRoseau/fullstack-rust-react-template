# Storage integration tests

Contains

- a Garage testcontainer to be reused for the tests (`common/containers.rs`)
- a `#[test_trait_suite]` module for the Storage trait, reused for every backend
  (`common/storage.rs`); the `s3` test binary is generated by `test_trait_main!`
- the Garage server configuration copied into that container (`assets/garage.toml`)

## Running

```sh
cargo test -p storage
```
